# Image Requirements

For the Call to Action component, please add an image file named `green-fields-aerial.jpg` to this directory. The image should be:

1. An aerial view of green fields/landscape
2. High resolution (at least 1920x1080px)
3. Properly licensed for commercial use

You can find suitable images on stock photo websites like Shutterstock, Adobe Stock, or free alternatives like Unsplash or Pexels.

Example search terms: "aerial view green fields" or "drone view agricultural landscape"
